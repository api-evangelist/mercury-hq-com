# MERCURY x402

> The agent-payable web-data network. 27 signed-provenance services an autonomous
> agent discovers, pays for with its own wallet (Base mainnet (eip155:8453) · real USDC · no token), and gets back the
> result PLUS a cryptographic receipt it can verify offline, forever — in ~5 lines of code.

## The wedge — why an agent picks MERCURY

> Firecrawl, Jina, and Tavily all gate behind a human-created API key + a credit-card plan,
> so an agent CANNOT onboard itself. MERCURY is KEYLESS: no API key, no signup, no account —
> an agent finds a SKU in the x402 Bazaar and pays with zero human in the loop. And every
> result ships an EIP-191 SIGNED provenance receipt (proof the bytes are genuine + untampered)
> that RAG, trading, and agent-to-agent commerce need and no plain scraper provides.

How to buy (x402 v2): GET https://network.mercury-hq.com/buy/<sku>?url=<target> with no payment returns HTTP 402 +
a payment-required JSON (price, payTo, network eip155:8453, facilitator). Pay with any x402
client (x402-fetch / x402-axios) and replay — you get the JSON result plus the signed
provenance attestation you can verify offline.
